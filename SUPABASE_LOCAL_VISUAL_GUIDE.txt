┌──────────────────────────────────────────────────────────────────────────────┐
│ PASSO 2: BAIXAR SUPABASE                                                     │
├──────────────────────────────────────────────────────────────────────────────┤
│  $ mkdir C:\Supabase                                                         │
│  $ cd C:\Supabase                                                            │
│  $ git clone https://github.com/supabase/supabase.git                       │
│  $ cd supabase/docker                                                        │
└──────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────┐
│ PASSO 3: CONFIGURAR .env                                                     │
├──────────────────────────────────────────────────────────────────────────────┤
│  Crie arquivo .env na pasta docker:                                          │
│                                                                              │
│  POSTGRES_PASSWORD=postgres                                                 │
│  POSTGRES_DB=postgres                                                       │
│  JWT_SECRET=super-secret-jwt-token-with-at-least-32-characters-long        │
└──────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────┐
│ PASSO 4: INICIAR SUPABASE                                                    │
├──────────────────────────────────────────────────────────────────────────────┤
│  $ docker-compose up                                                         │
│                                                                              │
│  ⏳ Aguarde 2-3 minutos...                                                   │
│  ✅ Quando pronto: "db | ready to accept connections"                      │
└──────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────┐
│ PASSO 5: CONFIGURAR BACKEND                                                  │
├──────────────────────────────────────────────────────────────────────────────┤
│  Arquivo .env do seu projeto:                                               │
│                                                                              │
│  DB_DRIVER=postgres                                                         │
│  PGHOST=localhost                                                           │
│  PGPORT=5432                                                                │
│  PGDATABASE=postgres                                                        │
│  PGUSER=postgres                                                            │
│  PGPASSWORD=postgres                                                        │
│  DB_SSL=false                                                               │
└──────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────┐
