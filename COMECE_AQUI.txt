❌ ERROS COMUNS E SOLUÇÕES:

┌─────────────────────────────────────────────────────────────────────────────┐
│ ERRO: "git not found"                                                       │
│ SOLUÇÃO: Instale Git (PASSO 1) e reinicie PowerShell (PASSO 2)              │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ ERRO: "Please tell me who you are"                                          │
│ SOLUÇÃO: Configure seu nome e email:                                        │
│   git config --global user.name "Seu Nome"                                  │
│   git config --global user.email "seu@email.com"                            │
│ Depois tente novamente                                                      │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ ERRO: "fatal: 'origin' does not appear to be a remote"                      │
│ SOLUÇÃO: Seu repositório não está vinculado. Execute:                       │
│   git remote add origin https://github.com/USUARIO/REPO.git                │
│ (Substitua USUARIO e REPO pelos seus)                                       │
│ Depois: git push origin main                                                │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ ERRO: "fatal: Authentication failed"                                        │
│ SOLUÇÃO: GitHub não aceita mais senha. Use GITHUB TOKEN:                    │
│   1. Acesse: https://github.com/settings/tokens                             │
│   2. Clique "Generate new token"                                            │
│   3. Marque: repo, read:user, user:email                                    │
│   4. Copie o token                                                          │
│   5. Quando git pedir password, cole o token                                │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ ERRO: "nothing to commit, working tree clean"                               │
│ SOLUÇÃO: Tudo já foi commitado. Para um novo commit:                        │
│   git commit --allow-empty -m "feat: QR Code v2"                            │
│   git push origin main                                                      │
└─────────────────────────────────────────────────────────────────────────────┘
